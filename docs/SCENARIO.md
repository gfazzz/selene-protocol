# Сценарий

**Спойлеры.** Сюжетный канон по сериям: сол, сцена, что говорит SELENE, чем
кончается серия и какой интерфейс пишет студент. Серии берут отсюда даты, имена и
сюжетные факты и на месте их не сочиняют. Сезоны после первого появятся здесь,
когда до них дойдёт работа.

---

## Персонажи

| Кто | Что известно |
|---|---|
| **ты** | техник по данным, первая смена в диспетчерской телеметрии Шеклтона |
| **Тамура** | сменщик, ночная смена; ворчит, но помогает; привык к лампе тревоги |
| **Окафор** | диспетчер дневной смены; ей нужен `toolkit` для своих сводок (с s01e06) |
| **Рейес** | твой предшественник, два года в диспетчерской, улетел на Землю за неделю до сола 1; его скрипты — источник большинства ошибок сезона |
| **SELENE** | пакеты с узла `0000`, которого нет в справочнике; отвечает на заметки в отладочном канале |

Правила для SELENE: сухо, коротко, с иронией по поводу регламентов; не хвалит.
В README она пишет заглавными в блоке `[КАНАЛ 0 · УЗЕЛ НЕ УКАЗАН]`; в theory.md
допустим эпиграф-цитата обычным регистром. Строки с узла `0000` видят все, но
считают их сбоем справочника. Что это **ответы**, до s01e08 знаешь только ты, и
никому об этом не говоришь.

Формат пакета (s01e01): `узел;датчик;значение;номер;тревога`, например
`0214;O2;20.90;118;0`. **Номер** — сквозной номер пакета в потоке смены, общий для
всех узлов; с каждой сменой он начинается заново. **Времени в пакете нет**: время
прихода берётся из метки приёма в архиве или из журнала смены.

Смены: ночная 20:00–08:00 (ты и Тамура), дневная 08:00–20:00 (Окафор). Тамура за
ночь уходит на обходы шлюзов и возвращается. Узлы — строки из четырёх цифр, справочник содержит узлы
`0001`–`3000`. Узел `0000` в справочнике отсутствует.

## Season 1 — Основы

Солы 1–40, кратер Шеклтона, диспетчерская телеметрии. Сквозной артефакт —
пакет `toolkit`. Сезон кончается тем, что ты находишь в журнале ответы SELENE
за годы до своего прихода, и один из них адресован Рейесу.

### s01e01 — Странный пакет · сол 1, 03:40

Написана. Узел 214 «молчит» из-за `int("0214")`, лампа горит из-за `bool("0")`.
Первые пакеты с узла `0000`: `ЕГО ЗОВУТ 0214`, затем `SELENE`.

### s01e02 — Первый выход за предел · сол 3, 02:15

Тамура жалуется, что проверка Рейеса «никогда ничего не находит». Регламент:
давление в отсеке 96–104 кПа включительно. Ночью давление в узле 1187 вышло за
предел в **самом первом** пакете смены, и проверка Рейеса его пропустила: она
писала `if index:` и считала нулевой индекс «ничего не нашли». В потоке также
пропуски номеров пакетов. SELENE: «ПЕРВЫЙ — ТОЖЕ НОМЕР. ДАЖЕ ЕСЛИ ЭТО НОЛЬ».

`toolkit/scan.py`:

```python
def first_out_of_range(values, low, high):
    """Индекс первого значения вне [low, high] (границы включены) или None."""

def count_out_of_range(values, low, high):
    """Сколько значений вне [low, high]."""

def first_gap(numbers):
    """Первый пропущенный номер в возрастающей последовательности номеров
    пакетов или None, если пропусков нет. [5, 6, 8] → 7; [] → None."""
```

Концепт: `if`, `while`, `for`, `break`, `None` как «не нашли». Без словарей,
без импорта, без исключений.

### s01e03 — Два имени одного окна · сол 6, 23:50

Табло диспетчерской из Рейесова скрипта: когда Тамура отмечает один отсек,
загорается весь столбец, потому что строки табло — один и тот же список.
Скользящие окна по давлению все одинаковы, потому что в результат добавлялся
один и тот же список. SELENE: «У ВАС ОДНО ОКНО И ВОСЕМЬ ИМЁН ДЛЯ НЕГО».

`toolkit/window.py`:

```python
def moving_windows(values, size):
    """Список окон длины size подряд: [1,2,3,4], 2 → [[1,2],[2,3],[3,4]].
    Каждое окно — отдельный список; входной список не меняется.
    size больше длины → []."""

def board(rows, cols, fill):
    """Табло rows × cols, заполненное fill; строки — независимые списки."""

def snapshot(window):
    """Неизменяемый снимок окна: кортеж; дальнейшие изменения окна его не трогают."""
```

Концепт: изменяемость, ссылки, `is` против `==`, кортеж как неизменяемое.
Без срезов (они в s02e01): окна строятся циклом.

### s01e04 — Сводка по узлам · сол 9, 01:30

Сводка за ночь: сколько пакетов от каждого узла, какие узлы молчат, какие не
числятся в справочнике. В «неизвестных» один узел — `0000`, и пакетов от него
больше, чем от любого настоящего. SELENE: «СПРАВОЧНИК — ЭТО МНЕНИЕ. ПОТОК — ФАКТ».

`toolkit/tally.py` (пакет — кортеж из `parse_reading`: узел, датчик, значение,
номер, тревога):

```python
def count_by_node(readings):
    """Словарь узел → число пакетов."""

def silent_nodes(registry, readings):
    """Множество узлов из справочника registry (множество строк), от которых
    нет ни одного пакета."""

def unknown_nodes(registry, readings):
    """Множество узлов из потока, которых нет в справочнике."""
```

Концепт: словарь, множество, операции над множествами, хешируемость ключа.

### s01e05 — Тревога, которая помнит · сол 14, 04:05

Функция тревог Рейеса копит тревоги между вызовами: в сводке узла 0042
оказываются тревоги узла 2210 из прошлой проверки. Причина — `found=[]` по
умолчанию. SELENE: «ФУНКЦИЯ ПОМНИТ ТО, О ЧЁМ ЕЁ НЕ ПРОСИЛИ. КАК ОТДЕЛ КАДРОВ».

`toolkit/alerts.py`:

```python
def collect_alerts(readings, low, high, found=None):
    """Список пакетов, чьё значение вне [low, high] или у которых поднят флаг
    тревоги. Если found передан — дописывает в него и возвращает его же;
    если нет — возвращает новый список."""

def format_alert(reading, prefix="ТРЕВОГА"):
    """'ТРЕВОГА 0214 O2 20.9 #118' — prefix, узел, датчик, значение, номер."""

def count_alerts(readings, low, high, counts=None):
    """Словарь узел → число тревог; та же договорённость, что у found."""
```

Концепт: функции, позиционные и именованные аргументы, значения по умолчанию
вычисляются один раз, `None` как маркер «не передано», область видимости.

### s01e06 — Инструмент общего пользования · сол 19, 08:00

Окафор хочет пользоваться твоими функциями в дневных сводках. Пакет Рейеса при
импорте печатает баннер и пишет файл `toolkit.lock` в текущий каталог, а
`from .x import *` вытаскивает наружу всё подряд. SELENE: «ИМПОРТ — ЭТО
ВОПРОС, А НЕ ПРИКАЗ. ВАШ ПАКЕТ ОТВЕЧАЕТ ПРИКАЗОМ».

Артефакт — `toolkit/__init__.py`. Каркас — каталог `starter/toolkit/`: модули
s01e01–s01e05 (эталонные), `__main__.py` (готовая сводка по `python -m toolkit`)
и `__init__.py` Рейеса с побочными эффектами. Студент переписывает только
`__init__.py`:

- явный импорт публичных функций из `.reading`, `.scan`, `.window`, `.tally`,
  `.alerts`;
- `__all__` с ровно этими именами;
- `__version__ = "0.1.0"`;
- никакого вывода и никаких файлов при импорте.

Концепт: модуль, пакет, `import` и `from … import`, `__name__ == "__main__"`,
`__all__`, побочный эффект импорта.

### s01e07 — Узкий перехват · сол 27, 03:20

Разбор Рейеса оборачивал всё в `except: pass`. Неделю назад так потерялась
настоящая авария: строка с давлением `9,6` (запятая) молча пропала, а вместе с
ней и сообщение о падении давления. SELENE: «ВЫ ПОСТРОИЛИ ДАТЧИК, КОТОРЫЙ НЕ
ВИДИТ ПРОБЛЕМ. ЭТО НАЗЫВАЕТСЯ НЕ ДАТЧИК».

`toolkit/errors.py` (самостоятельный модуль, разбор повторён внутри):

```python
class TelemetryError(Exception): ...
class BadPacket(TelemetryError):   # атрибут field — имя поля или None
    ...

def parse_strict(line):
    """Как parse_reading, но любое плохое поле → BadPacket с именем поля
    в сообщении и в атрибуте field; причина сохраняется (raise … from err).
    Не пять полей → BadPacket(field=None). Флаг не '0'/'1' → BadPacket('alarm')."""

def parse_all(lines):
    """(принятые, отклонённые): принятые — кортежи пакетов, отклонённые —
    пары (номер строки с 1, BadPacket). Ловит только TelemetryError: любая
    другая ошибка (например, None вместо строки) уходит наверх."""
```

`class` здесь — приём записи; классы разбираются в s02e03.

Концепт: исключения, иерархия, узкий `except`, `raise … from`, атрибуты ошибки.

### s01e08 — Ответ в журнале · сол 38, 02:00

Журнал смены — текстовый файл на смену: пакеты и заметки операторов вида
`# 23:10 кто это?` (только время: дата смены — в имени файла). Пакет с узла
`0000`, пришедший сразу после заметки, — ответ на неё. Ты прогоняешь старые
журналы и находишь, что SELENE отвечала и до тебя. В последнем журнале Рейеса,
за восемь солов до твоей первой смены: `# 03:55 ты кто вообще такая` — ответ
`ТА, КТО ОТВЕЧАЕТ`. Через сутки Рейес подал рапорт о переводе.
SELENE: «ТЕПЕРЬ ТЫ ЗНАЕШЬ, ПОЧЕМУ ВАКАНСИЯ БЫЛА СВОБОДНА».

Файлы серии: `data/shift_rejes.log` (последняя смена Рейеса) и
`data/shift_sol038.log` (твоя). Слаги каталогов серий сезона:
`s01e02-first-breach`, `s01e03-two-names-one-window`, `s01e04-summary-by-node`,
`s01e05-alarm-that-remembers`, `s01e06-shared-tool`, `s01e07-narrow-catch`,
`s01e08-answer-in-the-log`.

`toolkit/logfile.py`:

```python
def read_log(path):
    """Строки файла в UTF-8 без перевода строки в конце; пустые строки
    пропускаются; последняя строка без '\\n' не теряется; '\\r\\n' тоже."""

def selene_answer(line):
    """Текст ответа SELENE из одной строки журнала (поле датчика пакета с узла
    0000) или None, если строка — не пакет SELENE."""

def selene_answers(path):
    """Список пар (заметка, ответ): заметка — строка без '# ', ответ — поле
    датчика пакета с узла 0000, пришедшего сразу следующей строкой после
    заметки. Заметки без ответа не входят."""
```

Концепт: файл, `with open(..., encoding="utf-8")`, построчное чтение, перевод
строки, кодировка явно. Ось — воспроизводимость находки: тест генерирует журнал
с другим seed и требует найти ровно посаженные ответы.

### Детали, закреплённые в сериях

Появились при написании серий и теперь входят в канон:

- **s01e02:** на месте потерянного пакета 119 узла 1187 приходит
  `0000;ПРОВЕРЬ КЛАПАН;0.00;119;0`; три нарушения из четырёх за ночь — в первом
  пакете смены; наряд уходит в ремонтную службу.
- **s01e03:** спад давления по окнам виден на узле 0389, а не 1187: авария 1187
  случилась в первом пакете, и тренда к ней нет. Пакет SELENE в серии — № 611.
- **s01e04:** у SELENE пакетов больше, чем у любого настоящего узла; в утренней
  сводке два молчащих узла.
- **s01e05:** тревоги узла 2210 попадают в сводку исправного узла 0042; Тамура
  едва не поднимает ремонтную бригаду. В конце Окафор просит функции для дневных
  сводок.
- **s01e06:** дневная сводка Окафор — давление 96–104 кПа по датчику `P`; пакет
  `0000;ОТЧЁТ ПРИНЯТ;0.00` попадает в тревоги.
- **s01e07:** авария — на узле 0733, складском модуле с семенным фондом; запятая
  появилась после прошивки со сменой языка; потерянный пакет № 5521. Окафор ставит
  «отклонено пакетов» первой строкой своей сводки.
- **s01e08:** заметка в паре возвращается без `# `, но со временем:
  `"03:55 ты кто вообще такая"`.
