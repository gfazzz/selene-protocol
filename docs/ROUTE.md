# Маршрут

Пятнадцать сезонов, 174 серии, один путь по Луне. Шапки серий берут локацию, сол
и артефакт отсюда и на месте их не сочиняют.

**Длина сезона — по содержанию.** Серия — один концепт, который проходится за
45–90 минут одной задачей. Сезон состоит из стольких серий, сколько в нём таких
концептов; общего числа на сезон нет. Если при написании серия не помещается в
эти рамки, её делят здесь, в маршруте, и только потом пишут.

**Статус:** Season 1 написан; остальные сезоны — план. Сезоны 10, 11 и 14 могут
измениться после пилотов (см. [README](../README.md)).

## Оси проверки

У каждой серии одна **основная** ось. Определения — [SPEC.md](../SPEC.md) §1.

| Код | Ось |
|---|---|
| И | свойство и инвариант |
| Ф | поведение на фикстурах |
| Э | сверка с независимым эталоном |
| Н | воспроизводимость находки |
| О | поведение при отказе и повторе |
| Р | ресурс |
| К | разбор чужого кода |

## Что считается нарушением маршрута

- сол в шапке вне интервала своего сезона;
