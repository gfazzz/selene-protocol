## Обстановка

Ночной прогон Рейеса полгода присылал пустой лист: ошибку он печатал в отчёт и
завершался с кодом 0. Окафор нужна команда, которая даёт сводку или внятно
отказывает. Тебе — та же команда для ответов SELENE по всем журналам.

## Приказ

Дописать в `artifacts/toolkit/cli.py` функции `build_parser` и `main`.

## Договор вызова

```
python -m toolkit.cli summary ЖУРНАЛ [--low 96] [--high 104]
python -m toolkit.cli answers ЖУРНАЛ [ЖУРНАЛ ...]
```

`summary` печатает пять строк: журнал, принято, отклонено, тревог по давлению,
неизвестные узлы. `answers` печатает для каждого журнала заголовок `== путь` и
пары `заметка → ответ`. Обе строки результата собирают готовые функции
`summary_lines` и `answer_lines` — их не трогай.

| Ситуация | Код | stdout | stderr |
|---|---|---|---|
| успех | 0 | результат | пусто |
| `--help` | 0 | справка | пусто |
| журнал не найден или не читается | 1 | пусто | одна строка с именем файла |
| неверные аргументы | 2 | пусто | подсказка `usage: …` |

`main(argv=None)` возвращает код: `argv` — список аргументов без имени
программы, `None` — взять `sys.argv[1:]`. Процесс завершает одна строка под
`if __name__ == "__main__"`, она уже есть в каркасе.

## Критерии приёмки

- [ ] `main` возвращает целое число и не поднимает `SystemExit`.
- [ ] Сводка считает принятые, отклонённые, тревоги давления и неизвестные узлы.
- [ ] `--low` и `--high` доходят до расчёта; это числа, `abc` — код 2.
- [ ] `answers` обрабатывает все переданные журналы по порядку.
- [ ] Нет файла — код 1, строка в stderr, stdout пуст, без трассировки.
- [ ] Один плохой журнал из нескольких — код 1 и пустой stdout.
- [ ] Неверные аргументы — код 2, `usage` в stderr, stdout пуст.
- [ ] `python -m toolkit.cli` даёт тот же вывод, что `main`.
- [ ] `import toolkit.cli` ничего не запускает.
- [ ] `make test` → 19 зелёных проверок.
