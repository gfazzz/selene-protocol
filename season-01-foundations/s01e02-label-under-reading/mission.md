## Обстановка

Табло подписывает пакеты склейкой через `+` и `str()`: столбцы разъезжаются, коды
датчиков в разном регистре, у показаний двоичные хвосты. С другого конца зала
ничего не прочитать.

## Приказ

Написать `artifacts/toolkit/labels.py`: четыре функции, которые собирают строки
для табло и журнала по объявленному формату.

## Данные

Подпись пакета:

```
0214  O2       20.90  #000118
```

| Часть | Формат |
|---|---|
| узел | как есть |
| разделитель | два пробела |
| код датчика | через `normalize_code`, левый край, ширина 6 |
| значение | правый край, ширина 8, два знака после точки |
| разделитель | два пробела |
| номер | `#` и целое с ведущими нулями до шести цифр |

Ширина — минимум: длинный код или номер выходят целиком.

## Договор вызова

```python
normalize_code(" o2 ")                        # → 'O2'
format_reading("0214", "O2", 20.9, 118)       # → '0214  O2       20.90  #000118'
join_codes(["O2", "P", "CO2"])                # → 'O2, P, CO2'
field_note("value", "9,6")                    # → "поле value: '9,6'"
```

## Критерии приёмки

- [ ] Код датчика без пробелов по краям и заглавными; пробел внутри сохраняется.
- [ ] Подпись совпадает с образцом до символа.
- [ ] Обычное значение — восемь символов с двумя знаками, включая отрицательные и целые.
- [ ] У `0.1 + 20.8` на табло нет двоичного хвоста.
- [ ] Длинный код и длинный номер не обрезаются.
- [ ] Обычные подписи одной длины — 29 символов.
- [ ] Коды склеиваются через `', '`; пустой список — пустая строка.
- [ ] В пометке для журнала сырое значение видно целиком: кавычки, пробелы, `\n`.
- [ ] `make test` → 21 зелёная проверка.
