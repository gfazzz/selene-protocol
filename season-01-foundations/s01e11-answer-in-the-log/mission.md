## Обстановка

В архиве сотни журналов смен. В них заметки операторов и пакеты с узла `0000`,
которые на эти заметки отвечают. Найти их глазами можно один раз и с пропусками.
Нужна функция, которая находит их каждый раз одинаково.

## Приказ

Написать `artifacts/toolkit/logfile.py`: чтение журнала и поиск пар
«заметка — ответ».

## Данные

Журнал — текстовый файл в UTF-8, по строке на запись:

```
0214;O2;20.90;118;0              пакет, как в s01e01
# 01:18 узел 0000 — это кто?     заметка: '# ', время, текст
0000;НЕ УЗЕЛ;0.00;301;0          пакет с узла 0000 сразу после заметки — ответ
```

| Функция | Что возвращает |
|---|---|
| `read_log(path)` | список строк без перевода строки в конце; пустые пропущены |
| `selene_answer(line)` | текст ответа, если строка — пакет с узла `0000`, иначе `None` |
| `selene_answers(path)` | список пар `(заметка, ответ)` в порядке появления |

Заметка в паре — строка без `'# '`, вместе со временем: `"01:18 узел 0000 — это
кто?"`. Ответ — поле датчика пакета без пробелов по краям. Пустые строки в счёт не
идут: если между заметкой и пакетом `0000` только пустые строки, это ответ.

Журналы серии: [`data/shift_rejes.log`](data/shift_rejes.log) — последняя смена
Рейеса, [`data/shift_sol038.log`](data/shift_sol038.log) — твоя,
[`data/shift_rejes_first.log`](data/shift_rejes_first.log) — первая смена Рейеса,
до неё дойдёт s01e12. Собраны скриптом
[`tests/make_logs.py`](tests/make_logs.py) с фиксированным зерном генератора.

## Критерии приёмки

- [ ] Файл читается в UTF-8 явно — результат не зависит от настроек машины.
- [ ] Перевод строки в конце убран, в том числе `'\r\n'`.
- [ ] Последняя строка без перевода строки не теряется.
- [ ] Пустые строки и строки из одних пробелов пропущены.
- [ ] Ответ — только пакет с узла `0000`, идущий сразу после заметки.
- [ ] Заметка без ответа в список не входит; из двух заметок подряд ответ есть
      только у второй.
- [ ] На любом журнале, собранном тестом, найдены ровно посаженные пары.
- [ ] Последняя пара в журнале Рейеса — `("03:55 ты кто вообще такая",
      "ТА, КТО ОТВЕЧАЕТ")`.
- [ ] `make test` → 19 зелёных проверок.
