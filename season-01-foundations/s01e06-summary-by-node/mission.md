## Обстановка

Утром нужна сводка за ночь: сколько пакетов от каждого узла и что каждый узел
показал последним. Сводка Рейеса проходила поток заново для каждого узла
справочника, а последним считала то, что пришло позже, хотя задержанные пакеты
приходят не по порядку номеров.

## Приказ

Написать `artifacts/toolkit/tally.py`: три функции, каждая отвечает на свой
вопрос сводки за один проход по потоку.

## Данные

Пакет — кортеж из пяти значений, как его возвращает `parse_reading` из s01e01:

```python
("0214", "P", 100.2, 118, False)   # узел, датчик, значение, номер, тревога
```

Поток — список таких кортежей. Номер сквозной для смены; порядок прихода может с
ним расходиться.

| Функция | Что возвращает | Пример |
|---|---|---|
| `count_by_node(readings)` | `dict` узел → число пакетов | `{"0214": 3, "0000": 7}` |
| `last_value_by_node(readings)` | `dict` узел → значение пакета с наибольшим номером | `{"0389": 97.1}` |
| `values_by_node(readings)` | `dict` узел → список значений в порядке прихода | `{"0389": [100.2, 97.1]}` |

## Критерии приёмки

- [ ] Сумма счётчиков равна числу пакетов на любом потоке, включая пустой.
- [ ] Каждый счётчик равен числу пакетов своего узла; в словаре ровно узлы потока.
- [ ] Перестановка пакетов не меняет ни счётчики, ни последние значения.
- [ ] Ключи — строки номеров узлов, без превращения в числа.
- [ ] Последнее значение — из пакета с наибольшим номером, а не пришедшего
      последним.
- [ ] Значения узла — все, в порядке прихода; всех значений столько же, сколько
      пакетов.
- [ ] У каждого узла свой список: правка одного не меняет остальные.
- [ ] Поток после вызовов такой же, каким был.
- [ ] На пустом потоке — пустые словари.
- [ ] `make test` → 15 зелёных проверок.
