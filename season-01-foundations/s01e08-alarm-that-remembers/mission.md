## Обстановка

Функция тревог копит находки между вызовами: сводка по исправному узлу 0042
показывает тревоги узла 2210 из прошлой проверки. Ещё немного — и в жилой модуль
ушла бы ремонтная бригада.

## Приказ

Написать `artifacts/toolkit/alerts.py`: три функции, ни одна из которых не помнит
прошлых вызовов.

## Данные

Пакет — кортеж из `parse_reading` (s01e01):

```python
("2210", "P", 91.2, 40, False)   # узел, датчик, значение, номер, тревога
```

Тревога — пакет, у которого значение вне `[low, high]` (границы допустимы) или
поднят флаг тревоги. Регламент для давления: 96–104 кПа.

## Договор вызова

```python
collect_alerts(readings, 96, 104)               # → новый список тревог
collect_alerts(readings, 96, 104, found)        # → found, дополненный тревогами
format_alert(reading)                           # → 'ТРЕВОГА 2210 P 91.2 #40'
format_alert(reading, prefix="СБОЙ")            # → 'СБОЙ 2210 P 91.2 #40'
count_alerts(readings, 96, 104)                 # → {'2210': 2}
count_alerts(readings, 96, 104, counts)         # → counts, дополненный
```

## Критерии приёмки

- [ ] Тревога — значение вне `[low, high]` или поднятый флаг; границы допустимы.
- [ ] Тревоги идут в исходном порядке; входной список не меняется.
- [ ] Второй вызов не видит находок первого.
- [ ] Каждый вызов без `found` возвращает новый список, без `counts` — новый словарь.
- [ ] Переданный `found` (даже пустой) дополняется и возвращается тот же объект.
- [ ] Переданный `counts` дополняется: прежние числа складываются с новыми.
- [ ] Тревоги по частям в одном `found` совпадают с тревогами по всему списку.
- [ ] В счётчике только узлы с тревогами; сумма по узлам равна числу тревог.
- [ ] `format_alert` собирает префикс, узел, датчик, значение и номер с `#`;
      префикс по умолчанию — `ТРЕВОГА`, и он не залипает после другого префикса.
- [ ] `make test` → 19 зелёных проверок.
