## Обстановка

Неделю назад складской модуль у узла 0733 потерял давление. Пакеты о падении
приходили, но с запятой вместо точки, и разбор Рейеса выбросил их молча:
`except: pass`. Плохая строка должна стать громкой ошибкой с подробностями, а
ошибка в вызывающем коде — не прятаться среди плохих строк.

## Приказ

Написать `artifacts/toolkit/errors.py`: строгий разбор одного пакета и разбор
потока с разделением на принятые и отклонённые строки.

## Данные

Пакет — пять полей через точку с запятой: `0214;O2;20.90;118;0`. Классы ошибок
даны в каркасе:

| Класс | Предок | Что значит |
|---|---|---|
| `TelemetryError` | `Exception` | общий предок ошибок телеметрии |
| `BadPacket` | `TelemetryError` | плохой пакет; атрибут `field` — имя поля или `None` |

| Что сломано | `field` | Причина `__cause__` |
|---|---|---|
| не пять полей | `None` | — |
| значение не число | `"value"` | исходный `ValueError` |
| номер не целое | `"sequence"` | исходный `ValueError` |
| флаг не `"0"` и не `"1"` | `"alarm"` | — |

## Договор вызова

```python
parse_strict("0214;O2;20.90;118;0")   # → ("0214", "O2", 20.9, 118, False)
parse_strict("0733;P;9,6;5521;1")     # → BadPacket, field == "value"

accepted, rejected = parse_all(lines)
# accepted — кортежи пакетов в исходном порядке
# rejected — пары (номер строки с 1, BadPacket)
```

## Критерии приёмки

- [ ] Хороший пакет разбирается как в s01e01: узел и датчик без пробелов по краям,
      значение `float`, номер `int`, флаг `bool`.
- [ ] Плохое значение и плохой номер дают `BadPacket` с нужным `field`, именем
      поля в сообщении и исходным `ValueError` в `__cause__`.
- [ ] Флаг, отличный от `"0"` и `"1"`, даёт `BadPacket` с `field == "alarm"`.
- [ ] Строка не из пяти полей даёт `BadPacket` с `field is None`.
- [ ] `parse_all` возвращает принятые в исходном порядке и отклонённые с номерами
      строк, начиная с 1; принято + отклонено = всего.
- [ ] `parse_all` ловит только `TelemetryError`: `None` или число вместо строки
      роняет его, а не попадает в отклонённые.
- [ ] `make test` → 16 зелёных проверок.
