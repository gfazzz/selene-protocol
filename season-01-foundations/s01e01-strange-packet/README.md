## Диспетчерская, сол 1, 03:40

Вентиляция шумит на одной ноте. На табло три тысячи зелёных точек, одна красная,
и лампа общей тревоги над дверью. Лампа заклеена изолентой.

— Горит, сколько я здесь работаю, — говорит Тамура, твой сменщик по ночной
смене, застёгивая куртку. — Сводку
пишет скрипт, скрипт писал Рейес, Рейес улетел на Землю. Красная точка — узел 214.
Молчит с прошлой смены. Выпиши наряд на проверку, это Море Спокойствия, туда
двое суток.

Он уходит на обход шлюзов. Ты открываешь сырой поток: просто чтобы посмотреть, что значит
«молчит». Пакет — одна строка, пять полей через точку с запятой:

```
0214;O2;20.90;118;0
```

Узел, датчик, значение, номер пакета, флаг тревоги. Строки бегут. `0214` идёт с
тем же ритмом, что и все остальные. Узел 214 не молчит. Он докладывает: кислород
в норме, тревоги нет.

В сводке Рейеса ты находишь две строчки:

```python
node = int(fields[0])
alarm = bool(fields[4])
```

В справочнике узлов ключ записан как `"0214"`. Скрипт ищет там `214`, не находит и
закрашивает точку красным. А лампа над дверью горит потому, что `bool` от
непустой строки всегда истинен, и пакет с флагом `"0"` для скрипта — тоже тревога.
Обе ошибки об одном: **Рейес перепутал то, что видно, с тем, что это такое.**

В поле примечания отладочного канала ты пишешь, скорее себе, чем кому-то:

```
почему 214 красный, если он в потоке?
```

Следующая строка потока приходит с узла, которого нет в справочнике:

```
0000;ЕГО ЗОВУТ 0214;0.00;119;0
```

Формат соблюдён, все пять полей на месте. Потом приходит следующая:

```
0000;SELENE;0.00;120;0
```

Кода `SELENE` в справочнике датчиков нет.

> **SELENE — не декорация.** В сюжете её пока никто не видел. В реальности это **чат твоего редактора**: всё, что она «говорит», можно спросить по-настоящему. Только режим `Ask`, а не `Agent`: она объясняет, работу делаешь ты.

## Чему ты научишься

- Различать **значение, его тип и имя**, которое на него указывает.
- Превращать текст в число и обратно, понимая, что при этом теряется.
- Не доверять виду: `"0214"` не обязательно число, а `"0"` — не обязательно ложь.
- Приёму, который дороже синтаксиса: **тип выбирается по тому, что со значением
  будут делать, а не по тому, как оно выглядит.**

## Теория: значение, тип, имя

### Значение и его тип

Запусти `python3` и попробуй в интерпретаторе. У всего, с чем работает Python, есть тип:

```python
>>> type("118")
<class 'str'>
>>> type(118)
<class 'int'>
>>> type(20.9)
<class 'float'>
```

`"118"` и `118` выглядят похоже, но это разные значения. Тип определяет, что с
ними можно делать:

```python
>>> "118" + "1"
'1181'
>>> 118 + 1
119
>>> "118" + 1
TypeError: can only concatenate str (not "int") to str
```

Python не угадывает намерение, а сообщает об ошибке: неверное число могло бы
прожить в отчёте годы, а ошибка видна сразу.

### Из текста в число

Всё, что приходит из файла или сети, приходит текстом. Превращать его надо явно:

```python
>>> int("118")
118
>>> float("20.90")
20.9
>>> int("12.5")
ValueError: invalid literal for int() with base 10: '12.5'
```

`ValueError` здесь полезен: дробного номера пакета не бывает, и лучше узнать об
этом сейчас. Пробелы и перевод строки по краям `int` и `float` прощают.

Преобразование бывает с потерями. `int("007")` даст `7`, и два нуля исчезнут
навсегда. Если `007` — количество, ничего страшного. Если это имя агента, оно
потеряно. Спроси себя: **я буду с этим считать?** Индекс, номер телефона и
номер узла не складывают, поэтому они остаются строками.

### Истина — это тоже значение

Сравнение (`118 == 118`) возвращает значение типа `bool`: `True` или `False`.
Функция `bool` отвечает на другой вопрос: «пусто ли это?». Ноль и пустая строка
ложны, почти всё остальное истинно:

```python
>>> bool(0), bool(""), bool(0.0)
(False, False, False)
>>> bool("abc"), bool(" ")
(True, True)
```

Посмотри на примеры и предскажи, что вернёт `bool("False")`, прежде чем проверять.
Теперь ты знаешь, что случилось с лампой над дверью.

### Имя и неизменяемая строка

Присваивание не кладёт значение в ячейку. Оно привязывает имя к значению:

```python
>>> code = "  N2 "
>>> code.strip()
'N2'
>>> code
'  N2 '
```

`strip` не поменял строку, потому что **строку поменять нельзя**. Он создал новую и
вернул её, а поскольку имя к ней никто не привязал, она тут же пропала. Результат
надо сохранить (`code = code.strip()`) или сразу отдать. На этом попадается почти
каждый новичок, и ошибки при этом нет: код работает и молча делает не то.

## Проверка: SELENE задаёт вопросы

```
[КАНАЛ 0 · УЗЕЛ НЕ УКАЗАН]
ПРОЧИТАЛА СКРИПТ РЕЙЕСА. ТРИ ВОПРОСА, ПРЕЖДЕ ЧЕМ ТЫ СДЕЛАЕШЬ ТО ЖЕ САМОЕ.
```

**1.** «Что вернёт `bool("0")` и почему лампа над дверью не гаснет?»

<details><summary>Ответ</summary>

`True`. `bool` от строки проверяет только, пуста ли она, а в `"0"` есть один символ.
Содержимое никто не смотрел, поэтому тревогой считается каждый пакет. Вопрос
«значит ли это поле "да"» задают сравнением.
</details>

**2.** «Показание и номер пакета можно получить через `float`. Зачем тогда `int`?»

<details><summary>Ответ</summary>

У `float` конечная точность: 53 бита на мантиссу. `int(float("9007199254740993"))`
даст `9007199254740992`, то есть другой номер, причём без единой ошибки. Кроме того,
`int(float("12.5"))` молча даст `12`, а `int("12.5")` сообщит о мусоре.
</details>

**3.** «`code.strip()` отдельной строкой. Что изменилось в `code`?»

<details><summary>Ответ</summary>

Ничего. Строка неизменяема. `strip` вернул новую строку, и её никто не взял.
</details>

## Разбор типичных ошибок

1. **`int` для номера узла.** Ноль в начале пропадает, и `"0214"` перестаёт
   совпадать со справочником. Ошибка Рейеса.
2. **`bool(field)` для флага.** Истинно для любой непустой строки, включая `"0"`.
   Вторая ошибка Рейеса.
3. **`field.strip()` отдельной строкой.** Результат потерян, а исходная строка не
   изменилась. Ошибки нет, но тест на пробелы красный.
4. **`int(float(field))` для номера.** Большой номер искажается, а `12.5` молча
   превращается в `12`.
5. **Перехватить ошибку и вернуть `0`.** Показание «ноль кислорода» из мусорного
   поля хуже любого падения. Ошибки разберём в s01e07, а пока пусть доходят наверх.
