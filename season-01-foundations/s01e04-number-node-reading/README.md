## Диспетчерская, сол 4, 03:30

Утренний отчёт для начальника смены — два списка: «пять худших узлов за ночь»
(пять самых высоких давлений) и показания по порядку прихода с номерами строк.
Собирает его, как всё здесь, скрипт Рейеса.

Тамура, вернувшись с обхода, кладёт перед тобой вчерашнюю распечатку.

— В пятёрке худших 2210 выше 0042, — говорит он. — У обоих 104.5, но 0042
перевалил на час раньше. По отчёту выходит наоборот.

Ты открываешь скрипт. Пятёрка строится так:

```python
pairs = []
for reading in readings:
    pairs.append((reading[2], reading[0]))
top = sorted(pairs, reverse=True)
```

Кортежи сравниваются поэлементно: сначала значение, при равенстве — код узла.
`"2210"` больше `"0042"` как строка, и он встаёт выше. Время прихода в сортировке
не участвует вообще.

Список с номерами строк хуже. Узлы и показания приходят из архива двумя колонками,
в двух выгрузках, и скрипт склеивает их так:

```python
for node, value in zip(nodes, values):
    lines.append(node + " " + str(value))
```

Сегодня в выгрузке узлов на три строки больше: под утро был обрыв связи на
ретрансляторе. `zip` дошёл до конца короткого списка и остановился. Три последних
узла ночи исчезли из отчёта, и ничто не сказало, что их было больше.

Ты пишешь в поле примечания:

```
zip молча обрезал хвост
```

```
[КАНАЛ 0 · УЗЕЛ НЕ УКАЗАН]
ZIP, КОТОРЫЙ МОЛЧИТ О ЛИШНИХ, — ЭТО НЕ ZIP. ЭТО ЗАБВЕНИЕ.
```

Тамура читает через плечо: снова узел из ниоткуда, снова сбой справочника.

## Теория: встроенные функции обхода и распаковка

### Распаковка

Кортеж раскладывается по именам одной строкой:

```python
>>> pair = ("0042", 104.5)
>>> node, value = pair
>>> node
'0042'
```

Имён ровно столько, сколько элементов, иначе `ValueError: too many values to unpack`.
Звёздочка собирает «всё остальное» в список:

```python
>>> node, *rest = "0214;O2;20.90;118;0".split(";")
>>> node
'0214'
>>> rest
['O2', '20.90', '118', '0']
```

Обмен двух значений — тоже распаковка: `a, b = b, a`.
В s01e03 уже встречалась запись `for index, value in enumerate(...)`: это та же
распаковка, только на каждом шаге цикла.

### `enumerate` и `zip`

`enumerate` выдаёт пары «номер, элемент», начиная с номера из второго аргумента:

```python
>>> list(enumerate(["0042", "1187"], start=1))
[(1, '0042'), (2, '1187')]
```

`zip` идёт по нескольким последовательностям сразу и выдаёт кортежи. По умолчанию
он останавливается на **самой короткой**, и это не ошибка, а поведение:

```python
>>> list(zip([1, 2, 3], "ab"))
[(1, 'a'), (2, 'b')]
```

Если длины обязаны совпадать, так и скажи: `zip(..., strict=True)` поднимет
`ValueError: zip() argument 2 is shorter than argument 1`. Ловить её не надо: пусть
доходит до вызывающего. Ошибки разберём в s01e10.

### `sorted` и ключ

`sorted` возвращает **новый** список, а метод `list.sort()` сортирует сам список и
возвращает `None`: в первом случае вход остаётся каким был.

Что сравнивать, задаёт `key` — функция, которая по элементу возвращает то, по
чему его сортировать. Для пакета это значение, третий элемент:

```python
def value_of(reading):
    return reading[2]

ordered = sorted(readings, key=value_of, reverse=True)
```

Главное свойство, ради которого серия написана: **сортировка в Python устойчива**.
Элементы с равным ключом остаются в том порядке, в каком были на входе. С
`reverse=True` это тоже так:

```python
>>> pairs = [("a", 1), ("b", 2), ("c", 2), ("d", 1)]
>>> sorted(pairs, key=lambda pair: pair[1], reverse=True)
[('b', 2), ('c', 2), ('a', 1), ('d', 1)]
```

`b` пришёл раньше `c` и остался раньше: при сортировке только по значению порядок
прихода сохраняется сам. Рейес добавил в ключ код узла, и он пропал. (`lambda` —
короткая запись функции на месте; в решении хватит обычной `def`.)

### `min`, `max`, `sum`

`min` и `max` принимают `key` и при равенстве возвращают **первый** из равных; на
пустой последовательности — `ValueError`. `sum` на пустом списке даёт `0`.

## Проверка: SELENE задаёт вопросы

```
[КАНАЛ 0 · УЗЕЛ НЕ УКАЗАН]
ОТЧЁТ ПОЙДЁТ НАЧАЛЬНИКУ. ТРИ ВОПРОСА, ЧТОБЫ ОН ПОШЁЛ ПРАВИЛЬНЫЙ.
```

**1.** «Сортировка по паре `(значение, узел)` каждый раз даёт один и тот же
порядок. Почему он всё равно неверный?»

<details><summary>Ответ</summary>

Он одинаковый, но договорились о другом. При равных значениях решает код узла, а
отчёт должен показывать, кто перевалил первым. Сортировка по одному ключу —
значению — устойчива и сохраняет порядок прихода.
</details>

**2.** «Чем `sorted(readings)` отличается от `readings.sort()` для того, кто дал
тебе `readings`?»

<details><summary>Ответ</summary>

`sorted` возвращает новый список. `sort()` переставляет элементы того самого, и у
вызывающего поток меняется без предупреждения.
</details>

**3.** «Что вернёт `max(stream, key=value_of)`, если два пакета делят наибольшее
значение?»

<details><summary>Ответ</summary>

Тот, что встретился первым. Поэтому наибольший из `extremes` совпадёт с первым из
`worst`: обе функции опираются на порядок прихода.
</details>

## Разбор типичных ошибок

1. **Ключ из двух полей.** `(значение, узел)` ломает порядок прихода при равных
   значениях. Ошибка Рейеса.
2. **`sorted` по возрастанию и потом `reversed`.** Убывание получается, но равные
   встают задом наперёд: последний пришедший оказывается первым.
3. **`readings.sort(...)`.** Поток вызывающего переупорядочен. Тест сравнивает
   вход до и после.
4. **`zip` без `strict=True`.** Хвост пропадает молча. Вторая ошибка Рейеса.
5. **`for position in range(n)` с `ordered[position]`.** `IndexError`, если
   пакетов меньше `n`.
6. **`(None, None)` для пустого потока.** Похоже на ответ, а ответа нет: `None`.

## Debriefing

Новый отчёт ставит 0042 выше 2210: давление то же, но 0042 пришёл первым. Тамура
сверяет с журналом обходов и кивает. При разной длине выгрузок `pair_up` теперь
падает, и ночной прогон сообщает об обрыве, а не печатает укороченный отчёт.

Три пропавшие строки ты достаёшь из сырого потока вручную. Две — от узла 2210, и
обе выше предела. Третья — с узла `0000`:

```
0000;ХВОСТ ТОЖЕ СЧИТАЕТСЯ;0.00;2207;0
```

В отчёт она уходит строкой «сбой справочника», как все строки с `0000`. Что она
значит на самом деле, ты оставляешь при себе.

Тамура, уходя на обход, говорит, что завтра впервые всерьёз возьмётся за табло участка.

```
[КАНАЛ 0 · УЗЕЛ НЕ УКАЗАН]
ПОРЯДОК ЕСТЬ. ТЕПЕРЬ ПОСМОТРИ, СКОЛЬКО У ТЕБЯ НА САМОМ ДЕЛЕ СПИСКОВ.
```
