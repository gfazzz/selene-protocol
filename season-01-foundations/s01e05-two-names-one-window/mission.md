## Обстановка

Табло зажигает столбец вместо ячейки, а восемь окон давления одинаковы. Обе
ошибки об одном: там, где нужно несколько списков, есть один список под
несколькими именами.

## Приказ

Написать `artifacts/toolkit/window.py`: три функции, ни одна из которых не делит
свои списки ни с вызывающим, ни между результатами.

## Данные

| Функция | Что получает | Что возвращает | Пример |
|---|---|---|---|
| `moving_windows` | список значений, длина окна | список окон-списков | `[1, 2, 3, 4], 2` → `[[1, 2], [2, 3], [3, 4]]` |
| `board` | строки, столбцы, заполнитель | список строк-списков | `2, 3, "."` → `[[".", ".", "."], [".", ".", "."]]` |
| `snapshot` | окно-список | кортеж его элементов | `[101.2, 99.8]` → `(101.2, 99.8)` |

Длина окна — целое не меньше 1. Если она больше длины списка, окон нет: `[]`.
Срезы не нужны и ещё не введены: окно собирается циклом и `append`.

## Критерии приёмки

- [ ] Окна идут подряд, их ровно `len(values) - size + 1`, неполных окон нет.
- [ ] Входной список после `moving_windows` такой же, как до.
- [ ] Все окна — разные объекты (`is`), правка одного не трогает другие и вход.
- [ ] Окно на всю длину — новый список, а не сам вход.
- [ ] Табло нужного размера, строки — разные объекты.
- [ ] Отметка в одной ячейке табло не меняет других строк.
- [ ] Снимок — кортеж из элементов окна.
- [ ] Изменения окна после снимка снимок не трогают.
- [ ] `make test` → 19 зелёных проверок.
