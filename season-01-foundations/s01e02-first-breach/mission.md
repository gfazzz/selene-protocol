## Обстановка

Проверка давления за два года не нашла ни одного нарушения. Она пропускает
нарушение в первом пакете смены, потому что путает индекс `0` с «ничего не нашли».
В номерах пакетов тоже бывают пропуски, и их никто не ищет.

## Приказ

Написать `artifacts/toolkit/scan.py`: три функции поиска по последовательности.

## Данные

Регламент: давление от 96 до 104 кПа, **границы включены**. Функции получают
границы параметрами `low` и `high`.

| Функция | Что получает | Что возвращает |
|---|---|---|
| `first_out_of_range(values, low, high)` | показания | индекс первого вне `[low, high]` или `None` |
| `count_out_of_range(values, low, high)` | показания | число показаний вне `[low, high]`, `int` |
| `first_gap(numbers)` | возрастающие номера пакетов | первый пропущенный номер или `None` |

Примеры:

```python
first_out_of_range([95.8, 100.2, 101.0], 96, 104)   # → 0
first_out_of_range([100.0, 104.0, 96.0], 96, 104)   # → None
count_out_of_range([95.8, 100.2, 110.0], 96, 104)   # → 2
first_gap([117, 118, 120, 121])                     # → 119
first_gap([])                                       # → None
```

## Критерии приёмки

- [ ] Нарушение в первом пакете даёт `0`, а не `None`, `False` или пропуск.
- [ ] Находится первое нарушение, а не последнее.
- [ ] Возвращается индекс, а не показание.
- [ ] Значения ровно на границах — не нарушения.
- [ ] «Не нашли» — это `None`, а не `-1` или `False`.
- [ ] Подсчёт учитывает выходы и вниз, и вверх; пустой поток — `0`.
- [ ] `first_gap` возвращает сам пропущенный номер, и только первый.
- [ ] Пустой поток и поток из одного номера — без пропусков, `None`.
- [ ] `make test` → 24 зелёные проверки.
