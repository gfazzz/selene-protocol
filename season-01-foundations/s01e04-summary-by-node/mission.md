## Обстановка

Утром нужна сводка за ночь: сколько пакетов от каждого узла, какие узлы молчат и
какие шлют пакеты, хотя их нет в справочнике. Сводка Рейеса проходила поток
заново для каждого узла справочника, а про узлы вне справочника не знала вовсе.

## Приказ

Написать `artifacts/toolkit/tally.py`: три функции, каждая отвечает на один вопрос
сводки за один проход по потоку.

## Данные

Пакет — кортеж из пяти значений, как его возвращает `parse_reading` из s01e01:

```python
("0214", "O2", 20.9, 118, False)   # узел, датчик, значение, номер, тревога
```

Поток — список таких кортежей. Справочник — множество строк с номерами узлов:
`{"0001", "0002", ..., "3000"}`. Справочник общий для всей смены: менять его нельзя.

| Функция | Что возвращает | Пример |
|---|---|---|
| `count_by_node(readings)` | `dict` узел → число пакетов | `{"0214": 3, "0000": 7}` |
| `silent_nodes(registry, readings)` | `set` узлов справочника без пакетов | `{"0042"}` |
| `unknown_nodes(registry, readings)` | `set` узлов потока вне справочника | `{"0000"}` |

## Критерии приёмки

- [ ] Сумма счётчиков равна числу пакетов на любом потоке, включая пустой.
- [ ] Каждый счётчик равен числу пакетов своего узла; в словаре ровно узлы потока.
- [ ] Перестановка пакетов не меняет сводку.
- [ ] Ключи — строки номеров узлов, без превращения в числа.
- [ ] На пустом потоке — пустой словарь.
- [ ] Молчащие и докладывающие узлы не пересекаются и вместе дают справочник.
- [ ] Неизвестные узлы не пересекаются со справочником.
- [ ] Обе функции возвращают множества.
- [ ] Справочник после вызова такой же, каким был.
- [ ] `make test` → 16 зелёных проверок.
