## Обстановка

Утром нужен ответ: какие узлы молчат и какие шлют пакеты, хотя их нет в
справочнике. Скрипт Рейеса вычёркивал докладывавшие узлы прямо из общего
справочника смены и не задавал вопроса про чужих вовсе.

## Приказ

Написать `artifacts/toolkit/presence.py`: три функции, каждая отвечает на один
вопрос «кто», не трогая справочник.

## Данные

Пакет — кортеж из пяти значений, как его возвращает `parse_reading` из s01e01:

```python
("0214", "O2", 20.9, 118, False)   # узел, датчик, значение, номер, тревога
```

Поток — список таких кортежей. Справочник — множество строк с номерами узлов:
`{"0001", "0002", ..., "3000"}`, обычное или `frozenset`. Он общий для всей смены:
менять его нельзя.

| Функция | Что возвращает | Пример |
|---|---|---|
| `reporting_nodes(readings)` | `set` узлов, приславших хотя бы один пакет | `{"0214", "0000"}` |
| `silent_nodes(registry, readings)` | `set` узлов справочника без пакетов | `{"0042"}` |
| `unknown_nodes(registry, readings)` | `set` узлов потока вне справочника | `{"0000"}` |

## Критерии приёмки

- [ ] Все три функции возвращают множества.
- [ ] Докладывающие — ровно узлы потока, без повторов, при любом порядке прихода.
- [ ] Узел с единственным пакетом не теряется.
- [ ] Молчащие и докладывающие из справочника не пересекаются и вместе дают справочник.
- [ ] Неизвестные не пересекаются со справочником.
- [ ] Три ответа согласованы: докладывающие = справочник без молчащих плюс
      неизвестные.
- [ ] Справочник после вызова такой же, каким был; `frozenset` тоже принимается.
- [ ] На пустом потоке: докладывающих нет, молчат все, неизвестных нет.
- [ ] `make test` → 16 зелёных проверок.
