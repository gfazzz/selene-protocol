Источники идеи — [eurecable.com/ideas/987](https://eurecable.com/ideas/987)
(курс по Python: колония, девять сезонов, FastAPI и Django, ML и агенты, Mojo)
и [eurecable.com/ideas/979](https://eurecable.com/ideas/979) (MojoChain: ИИ на
сети из множества слабых машин вместо дата-центра — в курсе это устройство
мира, а не отдельная тема).

**15 сезонов, 174 серии, около 160 часов.** Длина сезона — по содержанию: серия — один концепт на 45–90 минут. Python целиком: основы и
питонизмы, данные и SQL, числа, деньги, сеть и `asyncio`, **FastAPI**,
**Django**, машинное обучение, **своя языковая модель на NumPy**, **чтение
исходников grok-1**, распределённые вычисления, производительность, **Mojo**,
финальная приёмка.

Три решения, отличающие эту версию от первой заготовки:

- **веб — два сезона, а не строчка «упоминается»:** FastAPI как витрина
  расчётов, Django как реестр с правами и аудитом;
- **модели — два сезона:** сначала трансформер, написанный целиком на NumPy,
  потом чтение промышленного кода (grok-1, Apache 2.0) и перенос его
  механизмов в масштаб, который влезает в память;
- **Mojo — свой сезон:** горячее ядро из Season 10, найденное профилем в
  Season 13, переписывается и замеряется против NumPy.

Ключевое решение по проверке: **тест проверяет свойство, а не константу.** Не
«результат равен 0.7351», а «оценка сходится к параметру», «сумма частей равна
целому при любом разбиении», «маска внимания не пропускает будущее», «повтор
запроса не создаёт вторую запись». Иначе курс учит подгонять число под ответ.

Формат серии — **как в OPERATION MOONLIGHT**: одна серия — один концепт — один
артефакт — зелёный тест. Четырёх типов серий из KERNEL SHADOWS здесь нет:
там они разделяли работу разной природы, здесь артефакт — `.py`
([почему](SPEC.md#почему-в-шапке-нет-строки-тип)). Вместо баланса типов в
критерии приёмки сезона входит покрытие **осей проверки** — не меньше трёх
разных способов узнать, что код верен, на сезон.

**Быстрый старт:**

```bash
make setup
cd season-01-foundations/s01e01-strange-packet
make start
make test
```

Начало курса — [`s01e01`](season-01-foundations/s01e01-strange-packet/README.md).
Нужен Python 3.12 или новее. `make check` в корне прогоняет все проверки курса.
